# Sistema de Soporte Académico

## Laboratorio 02 - Funciones y modularidad en C#

Este proyecto permite registrar solicitudes de estudiantes para un módulo de soporte académico.

El sistema solicita el código, nombre, tipo de consulta y descripción. También valida los datos, asigna una prioridad y muestra un resumen de cada solicitud.

## Funciones y requerimientos

| Función | Tipo | Requerimiento |
|---|---|---|
| MostrarMenu | void | 4 |
| RegistrarSolicitud | void | 1 y 10 |
| ValidarCodigo | bool | 2 |
| ValidarTipoConsulta | bool | 3 |
| CalcularPrioridad | string | 5 |
| ValidarTexto | bool | 6 y 9 |
| MostrarResumen | void | 7 y 8 |
